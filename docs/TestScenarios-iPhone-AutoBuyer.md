# 本轮验收场景

## v0.5.3 新增

| 起始条件与任务 | 操作 | 可观察结果 |
|---|---|---|
| 尚未登录，购物袋菜单延迟出现 | 从软件点预登录 | 商店到购物袋再点击唯一官方登录链接；保留官网生成的跳转参数，未直达账户认证 |
| 商店记住账户、账户认证仍有效 | 再点预登录、确认返回 | 沿官网当次账户链接核对受保护页面；不提交密码，原会话保持 |
| 商店记住账户、实际账户已过期 | 再点预登录、确认返回 | 账户页要求登录时暂停；购物袋退出登录不能被误报为认证成功 |
| 旧预约使用其他时区 | 更新、保存并重开软件 | 界面只有北京时间，实际开售时刻保持不变 |
| 购物袋登录路径为 `/shop/signIn?…` | 诊断或正常表单登录 | 正确认识路径，不覆盖当前登录表单；相似前缀、伪装域名、其他端口不允许 |
| 购物袋出现多个登录链接或外站链接 | 自动打开登录入口 | 保留商店页，请用户选择，不自动发送账户信息 |
| 软件 Chrome 保存有期限及无期限 Cookie | 正常退出再打开 | 两者均恢复；旧登录/结账标签页不会自动重载；日常 Chrome 不受影响 |
| 中国区或全球 Apple 认证框架，一步或两步登录 | 用户预选自动登录，再遇到正常商店登录表单 | 两个合法认证域名均识别；仍校验父页面、来源和表单用途 |
| 正常认证初始化成功，提交返回 503 / HTML | 继续检查登录 | 显示认证服务失败，保留页面；同一密码仅提交一次，不自动转游客 |
| 辅助资源返回 503，真正商店资源正常 | 判断商店是否繁忙 | 辅助资源不能让商店被误判为维护；关键认证与商店错误分别处理 |
| 登录诊断正在运行 | 切换界面页、查看来源、尝试切换浏览器 | 显示实际浏览器；任务中模式选择禁用；诊断随同一会话记录 |
| 认证响应包含账户、令牌或完整错误正文 | 保存诊断 | 仅保存固定分类、公开主机、状态和数字错误码；敏感原文不落盘 |
| 软件 Chrome 原有进程与资料目录存在 | 自动化断线后恢复连接 | 合成 Cookie 与原页面恢复；不改变浏览器属性、不接管日常 Chrome |
| 用户普通网页在当前网络能登录 | 与新版软件 Chrome 单次实际登录对照 | 记录各自结果；普通网页登录、iCloud 密码验证和合成测试不替代软件中国商店认证 |

## v0.5.1 新增

| 起始条件与任务 | 操作 | 可观察结果 |
|---|---|---|
| 尚未保存账户或未勾选权限 | 官网显示登录表单 | 不读取钥匙串、不填写密码 |
| 一步或两步 Apple 官方登录表单 | 开启保存账户自动登录 | 账户、密码只提交一次；仅预选时勾选记住账户 |
| 密码被接受后要求验证码 | 完成首次验证、官网询问信任 | 保留页面；验证码空白等本人；预选信任才点对应选项 |
| 密码失败、无法验证身份或不确定返回 | 再点继续检查 | 不重发同一密码、不自动改用游客 |
| 加载页或关键 541 | 检查登录 | 不读取密码，不增加登录提交 |
| 后台账户检查需要验证码 | 本人在保留的检查页完成登录，再检查 | 复用原检查页，确认成功才关闭；原购买页保留 |
| 外站、取货信息、改密码页或不同账户的密码页 | 自动登录 | 不填写账户密码 |
| 保存、替换账户或导入配置 | 管理本机设置 | 账号密码仅进钥匙串；文件只有随机引用；导入关闭权限 |

## v0.5.0 新增

| 起始条件与任务 | 操作 | 可观察结果 |
|---|---|---|
| Duo 无购买链接、门店未读过库存 | 在软件目录选上海和北京门店，筛选杭州后保存 | 链接仍可留空，两家各自地区、启用状态和顺序保持，不显示有货 |
| 首选上海、第二北京、第三上海、第四杭州 | 查询供货 | 上海一次查询，北京次序不能被第三门店抢先跳过；前序合适后不查杭州 |
| 页面载入、503 维护、明确 Apple 登录 iframe | 检查登录 | 前两者未知，真正表单需登录；保留浏览器与 Cookie，不重发密码 |
| 取货页面包含邮箱和电话 | 继续填写 | 联系字段不能误报为登录表单 |
| 用户预选游客备用 / 仅账户 | 官网实际出现游客入口 | 备用仅点一次；仅账户保持页面等登录 |
| 取货资料已填写，实际出现验证码 | 再次继续 | 继续暂停提醒验证，不自动请求短信、不跳过验证 |
| 内嵌主页面已打开 | 新建检查页、关闭检查页、断开再连接 | 原主页面与会话仍在，同一资料目录正常退出再打开可恢复合成会话 Cookie |
| 原软件 Chrome 进程仍在，自动化连接丢失 | 重新打开软件会话 | 严格匹配用户、可执行文件和私有目录，恢复原页面，不接管日常 Chrome |
| 正在保持会话 | 关闭窗口，再退出软件 | 关窗后台保留；退出结束线程和页面后再销毁资料，无意外退出 |

真实 Apple 登录、官网库存读取与以上离线机制测试分开记录。多代理、Safari 自动购买和双入口首发性能没有验收通过，不发布这些能力。

按 [test-scenarios](https://github.com/phuryn/pm-skills/blob/c68487d721e419ec87af1ae6412a842978eab785/pm-execution/skills/test-scenarios/SKILL.md) 整理。角色为本机 Mac 用户；网络夹具全部拦截，不调用 Apple 订单服务。

| 起始条件与任务 | 操作 | 可观察的结果 |
|---|---|---|
| 已通过辅助功能读取过有数据的表格 | 改变行数、切换门店与运行记录、退出并重开 | 窗口和辅助功能对象正常销毁，进程退出 0，无新的 macOS 崩溃报告 |
| 工作线程仍在运行 | 关闭窗口或退出 Qt 事件循环 | 停止任务并等待线程清理完成，计时器停止，再销毁父窗口；不出现 QThread Destroyed |
| 当前目录已缓存，选择 Duo | 点机型、颜色和容量 | 中文选项、官网价；无手输链接或预算 |
| 18 Pro Max 的价格与 Pro 不同 | 选 Max + 512GB，保存并重读 | 官网机型原值保留；价格为 Max 的 12,999，未混用 Pro 的 11,999 |
| 招商银行 24 期及两个备用方式 | 点选、排序、保存并重读 | 顺序与期数准确；未选的授权仍关闭 |
| 新官网金额尚未接受 | 显示金额按钮，先保持暂停，再接受 | 只有接受相同商品、数量和金额后继续；旧确认不能授权新增数量 |
| 200 维护页 / 503 拥堵 | 正常检查、503 指定等待中尝试刷新 | 未误报 541；指定时间前无第二个 GET |
| 官网已进入等待室 | 保留页面，页面自行放行 | 不发刷新；放行后可继续 |
| 当前页面正在加载 | 等到完成或明确失败 | 不循环取消进行中的页面请求；旧账户页不能当作目标商品 |
| 明确 429 / 541 | 继续、重启后再检查 | 冷却生效、可见剩余时间；相同页面多个拒绝不是多个重试回合 |
| 登录返回换到了软件的新标签 | 关闭旧页、完成返回，再检查 | 软件只识别自己的账户页，不再提交密码或关闭整个会话 |
| 缺少产品 URL | 发布一个唯一官网入口，或制造同名冲突 | 前者采用实际链接，后者等待；错误域名被拒绝 |
| Apple 要求数据隐私确认 | 点击软件“已在官网处理”但官网仍未同意 | 重新检查后继续暂停，软件没有替用户勾选协议 |
| 当次隐私确认 | 两项均点选，点击“本次同意并继续” | 只匹配当前协议并执行一次；改变正文、额外授权、过期或停止任务均不能复用 |
| 开售前提前同意隐私声明 | 付款页勾选两项、保存、重启后运行 | 两项仍保存；同一声明自动同意并继续，没有等待用户的弹窗 |
| 只勾一项或旧声明版本 | 保存后运行 | 不自动同意；默认、导入配置与部分选择都不冒充完整同意 |
| 提前同意后声明变化 | 修改段落、两项文案、添加选择或在按钮后新增条款 | 均不自动同意，展示当前声明重新选择 |
| 关闭了当前协议弹窗 | 点“付款与授权”或控制台的隐私入口 | 重开同一协议，两项仍未勾选；不存在待确认协议时入口不可用 |
| 新建取货人 | 只填写四位数字或末位 X，不输入证件类型 | 可以保存；完整号码与错误长度保留输入并提示修改，不静默截取 |
| 编辑旧的完整证件资料 | 打开、取消，再打开保存 | 表单只有后四位；取消不修改原资料，保存仅留四位 |
| 首发入口持续繁忙 | 请求消耗两秒，持续超过两分钟 | 请求开始间隔持续五秒；实际加载和队列不打断 |
| 公开入口暂时异常 | 403/429/541 无服务端等待或带 Retry-After | 默认五秒起、连续失败退避；服务端等待优先；登录/变更/下单不自动重发 |
| 错误页有主标题 | 541 文档含 H1，默认等待已过 | 未收到正常文档仍视为未进入，下一次正常 GET 才可恢复 |
| 重启官网试跑，购物袋有商品 | 正确目标、错误型号后缀、错误数量、真实购买分别测试 | 只在试跑且型号/配置/数量/金额一致时复用；没有加购、删除或数量变更 |
| 订单提交结果未知 | 停止、重启和恢复 | 原订单锁保留，只查询状态；不第二次下单 |

实际官网另检验：软件登录、在售 iPhone 的公开供货，以及能到达的真实试跑阶段。未开放的 Duo 结账与银行支付不以离线夹具冒充成功。
