实际安装版下拉已检查：Duo、17、17e、18 Pro、18 Pro Max 共五个型号。切换 Duo 后原机型颜色、容量不会自动沿用，显示「请选择」及官网预购说明。付款页保留招商银行 24 期，首选、备用方式、期数和授权均可直接点选；没有输入文字确认的步骤。实际授权开关仍关闭。

原生截图分别为 [商品页](images/product-v040.png)、[付款页](images/payment-v040.png)，已经逐项查看。两图没有账户、联系人、验证码、订单令牌或付款码。「使用官网开售时间」在实际窗口正确显示北京时间 2026-10-16 20:00 与柏林时间 14:00，检查后恢复原现货试跑配置。最终安装版 Apple 登录在 01:24:51 UTC 重新确认成功；界面截图本身不证明首发下单成功。

以下为 v0.3.0 设计基准与当时检查，保留为历史。

## 设计基准

使用 frontend-app-builder 的完整视觉稿流程，以及内置 Image Gen（ui-mockup）。基准是 `reports/ui-concept-v03.png`，1536×1024。保留六页及原有授权条件，目标是原生 Qt 窗口，不增加网页实现。Browser/IAB 不能渲染原生 Qt 窗口，因此最终使用 macOS 原生窗口、实际点击和窗口截图验证。

- 白色内容区 `#ffffff`，侧栏 `#f2f2f5`；文字 `#242426` / `#74747a`，分隔线 `#e5e5ea`，主色 `#007aff`。
- 侧栏占约 16.4%，使用 16–18 像素、同一笔画的轮廓图标；自绘图标与字母 A 保持矢量和代码实现。
- 导航仍为商品配置、自提门店、取货人、付款与授权、控制台、运行记录。
- 控制台使用顶部操作栏、安静的实际状态行、两栏工作区，以及底部日志。
- 左栏是购买计划摘要、开售与检查设置；右栏是登录会话、保持唤醒、付款码操作和帮助。
- 表单采用固定标签宽度、普通控件、小圆角和细线；不使用大时钟、指标卡片、虚构的库存或登录成功。

## 内容与行为约定

标题及按钮按视觉稿：控制台、准备检查…、官网模拟下单、开始抢购、购买计划、编辑配置、开售与检查、软件浏览器、登录并保持会话、检查登录状态、关闭会话、查看付款二维码、提取当前付款码、使用帮助、运行日志、继续检查、停止任务、诊断…。

当时的商品、颜色/容量、数量、预算、门店、付款、日期、时间和阶段都是配置或观测值。视觉稿中的 iPhone 17、RMB 7,000 和 10 月 16 日是示例；实现不能无条件写死这些值。v0.4.0 已删除手填预算，改为目录价格。启动时显示尚未开始和登录未检查。请求被拒绝后显示实际状态与恢复办法，不能保持伪成功状态。

时区选择显示北京时间/柏林时间/UTC，内部仍保存完整 IANA 时区；转换保持同一预约时刻。系统原生日期、复选框、数值控件与 title bar 的绘制，以及当前实值与设计示例的差别，是预先允许的差异。所有控制文字均由 Qt 渲染。

## 最终视觉与交互核对

基准 `reports/ui-concept-v03.png` 与安装版 `reports/ui-v030-release-native.png` 已分别通过 view_image 查看。最终窗口为 v0.3.0 / build 6 的实际 macOS 窗口截图，不是 HTML 或生成图。原生窗口无法通过 Browser/IAB 做视口测试，已改用 macOS CUA 的实际点击与 Qt 尺寸检查。

| 对照项 | 视觉稿 → 安装版 | 结果 |
|---|---|---|
| 主布局 | 六页侧栏、顶部操作、两栏工作区、底部日志 → 相同层级与位置 | 匹配；侧栏 210/1280，约 16.4% |
| 购买计划 | 手机轮廓、商品与配置、三行摘要、细线 → 同样结构 | 当前配置实值；预算明确写上限 |
| 浏览器区 | 登录状态、登录/检查/关闭、保持唤醒、付款码、帮助 → 同样顺序 | 关闭按钮随实际会话启用 |
| 字体层级 | 大标题、分区标题、商品名称、正文、灰色辅助 → 24/16/17/13 像素及系统字体 | 原生字体度量允许差异，层级一致 |
| 颜色和边线 | 白底、浅灰侧栏、蓝色选中、细灰分隔线 → 对应 QSS 色值 | 无渐变或额外状态卡片 |
| 图标 | 轮廓导航、手机、帮助、时钟 → 统一 1.6 描边 SVG 与 Retina 绘制 | 原生 A 图标字形略小；沿用应用字母图标 |
| 留白与对齐 | 紧凑表单、固定摘要标签、两栏分隔 → 24 像素外边距、固定标签和同一分隔线 | 默认窗口没有内容裁切 |
| 文字与状态 | 设计基准的固定标题/按钮 → 原文保留 | 拍摄当时等待验证码；未显示伪登录成功 |

**文案差异核对：** 固定标题与按钮逐项对照。图中的 10 月 16 日为示例；实际未预约时显示当前编辑时间。用户配置保留柏林时区，故显示「柏林时间」；内部仍保存 IANA 时区。浏览器辅助行在会话打开后显示实际「Google Chrome（软件独立会话）」。状态、日志、按钮启用和时钟随真实运行变化，是既定动态字段。颜色和容量表格改为「颜色 / 白色」「存储容量 / 256GB」；收集结果仍为准确官网原值，回归验证通过。

**尺寸：** Qt 渲染检查默认 1280×825 时横纵滚动条均为 0，日志高 118；最小 1060×720 时无横向滚动、纵向滚动最大 97，所有控件可以纵向访问。证据 `reports/ui-v030-layout.json`、`ui-v030-size-1280.png`、`ui-v030-size-1060.png`。最小尺寸是 Qt 渲染检查；真实 macOS 窗口核对默认尺寸及 Retina 截图。

**实际交互：** macOS 窗口打开帮助、返回控制台、打开准备清单、通过编辑配置切换页面，侧栏选中同步；安装版又验证诊断环境检查、中文商品配置和返回控制台。拍摄时软件暂停等待 Apple 设备验证码；本人随后完成验证，v0.3.0 登录在 2026-10-12 00:18:52 UTC 确认。官网库存两次真实读取另见 VERIFICATION.md，视觉稿不作为功能证据。
