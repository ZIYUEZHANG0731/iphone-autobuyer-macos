# Windows 挂机使用说明

适用 v0.7.13 / build 56。软件可预约等待、查询允许门店、自动填写、核对并按授权提交一次；当前真实 Windows 验收完成到最终核对页，真实订单提交仍需单独验收。Apple 临时验证码、安全验证和实际付款需要本人处理，不能承诺永久免验证或保证抢到库存。

## 开始前

1. 完整解压便携包，双击 exe。保存商品、数量、允许门店优先级、默认取货人和付款方案。
2. 选择「软件内置浏览器」或「独立 Chrome · 软件专用会话」，点击登录并确认控制台显示「登录已确认」。这些会话各自保存，日常 Chrome 的登录不能替代它们。
3. 先点「官网模拟下单」。核对商品、数量、总额、门店及付款方案，结果应为「已完成」，并显示未提交真实订单。混合购物袋、数量不符或金额不符会被拒绝；由本人整理购物袋后再核对。
4. 正式购买时保存「条件满足后自动提交订单」，在控制台勾选预约并设置**北京时间**，再点「开始抢购」。软件不会把模拟下单变成真实购买。预约账户模式必须先确认登录，开售前十分钟再检查当前会话。

保持电源、网络和软件会话可用。防止空闲睡眠仅在会话保持期间生效，系统强制睡眠、关机或断网仍会中断任务。关闭主窗口时，有会话则隐藏到托盘；托盘菜单可恢复窗口或退出。

## 自动恢复与暂停

| 情况 | 软件行为 |
| --- | --- |
| 商店尚未开放 | 按已保存的 5 秒刷新／停留策略等待；正在加载的请求保留 |
| 允许门店缺货 | 按优先级和已保存的无货策略处理；不自动改为配送 |
| 页面仍在保存选择 | 等待原请求完成，成功后自动继续；不重复加购 |
| 购物袋／结账文档 GET 返回 500、502、503、504 | 按 5／10／20 秒最多恢复三次，并遵守更长的服务器等待 |
| 账户验证码 | 保留官网，提醒本人完成；正常返回后自动检查并继续，不输入验证码或重发密码 |
| 取货手机验证 | 保留已填写资料，本人完成官网验证后点「继续检查」 |
| 失败的购买保存、安全挑战或不明确页面 | 暂停并保留购物袋，提示需要处理 |
| 购物袋与配置不符或其他失败 | 停止本次任务并发送托盘通知，不自动移除其他商品 |
| 提交结果未知 | 保留持久订单锁，只核对已有结果，禁止盲目再次下单 |
| 已确认待付款订单 | 停止自动提交，显示付款信息，由本人付款 |

「停止任务」保留浏览器连接；「关闭会话」释放自动化连接和防睡眠状态，专用 Chrome 正常关闭。内置网页由软件界面管理，彻底退出软件时关闭。

## 订单锁

每个购买计划有独立 intent。SQLite 在提交前原子保存订单锁，停止、崩溃和重开都不能清除它。结果不明时先通过 Apple 正常订单页面确认，不能用新任务或新浏览器反复下单。需要另购时才创建新的购买计划，旧订单和旧锁保留。
