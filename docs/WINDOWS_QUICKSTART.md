# Windows 便携版使用

适用 Windows 11 x64。把 ZIP **完整解压**到本机中文或含空格的目录，再双击 `iPhone AutoBuyer.exe`。exe 必须与 `_internal` 保持相邻，不需要安装 Python 或 Node.js。当前版本未签名；若本机策略拦截，请记录具体提示。

内置浏览器随软件提供。独立 Chrome 模式使用本机正式 Google Chrome；未安装时可在软件中安装 Chromium。浏览器缓存按当前 Windows 用户保存。

第一次打开后，在「官网浏览器」填写 Apple 账号并正常完成官网验证，填写取货人，保存商品和允许门店。Windows 数据保存在 `%LOCALAPPDATA%\Apple AutoBuyer`，退出重开后自动载入本机加密资料；不要复制其他电脑的密钥或浏览器资料。

先用「官网模拟下单」检查商品、门店和付款方案，到核对页停止。真实购买需要单独开启自动提交并运行「开始抢购」。验证码和实际支付由本人完成；未知提交结果的订单锁会保留。

v0.7.13 / build 56 提供「软件内置浏览器」和「独立 Chrome · 软件专用会话」两种直接连接方式。内置模式在软件中显示官网；独立模式启动软件自己的 Chrome，保留该窗口中的登录与购物袋，点击「独立 Chrome 登录」即可开始。日常 Chrome 模式仍通过官方扩展选择和授权页面；三个模式的会话分别保存，不能用另一个窗口的登录代替当前会话检查。

本版修复加购慢跳转和购物袋保存误判；实际购物袋须完整、稳定且符合商品、数量和金额设置，才会继续结账。已经加购时沿原袋继续核对。

登录会等待官网表单载入，正常返回中国商店 `/store`、中国官网首页或送货／取货选择页后继续确认，不再把这些返回误报为登录失败。官网账户验证码由本人填写；完成账户验证后自动观察返回并继续，不重发密码。预约「只用 Apple 账户」前必须确认登录有效，开售前十分钟再次检查。

保存门店、取货时段等选择时，先等待官网请求完成。超过正常等待仍保留原请求；成功完成后自动继续核对，失败时保留购物袋。购物袋／结账文档 GET 遇到 500、502、503、504，可按 5／10／20 秒最多恢复三次，并遵守更长的服务器等待；账户认证、购买 POST 和订单提交不自动重发。

内置官网试跑时自动收起登录设置，给网页留出完整操作区域。「窗口置顶」方便看全流程，取消勾选即可恢复普通窗口。会话期间防止空闲睡眠；停止任务保留浏览器，关闭会话释放自动化连接。失败、需要验证、订单结果不明和待付款会发送托盘通知；购物袋不符不会自动移除其他商品。接通电源并保持网络可用，电脑关机或系统强制睡眠时任务无法继续。

v0.7.9 已迁入 macOS 的连接复用和取货时段处理：已连接时再次点击「接入日常 Chrome」只前置当前 Apple 页面；等待连接时不会另外打开授权页。官网显示必选签到时段时，保留有效选择，否则选首个可用时段并等官网保存。停止任务保留已建立的连接，关闭会话或退出软件后需重新建立。控制台新增入口刷新 / 停留策略，只作用于尚未进入购买流程的公开页面。

复用已有购物袋时，若官网尚未选择地区，软件按首选允许门店的省市、区县设置地区，再核对门店编号、供货和优先级。地区保存失败会暂停并保留购物袋。若显示「需要手机验证」，这已是取货信息阶段；完成官网验证后再点「继续检查」。

会话开启时关闭窗口会隐藏到托盘，点击托盘图标恢复。托盘菜单提供「显示窗口」「关闭会话」「退出软件」。彻底退出使用托盘菜单。

## 离线自检

解压目录中的两个 PowerShell 脚本必须保持相邻。以下命令不会访问 Apple，报告及合成数据写入临时目录：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\self-test.ps1" -Distribution "."
```

如需验证独立 Chromium 与合成订单，并下载本机浏览器缓存：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\self-test.ps1" -Distribution "." -InstallChromium
```

自检通过只能确认环境、界面、内置渲染器及合成购买流程。真实官网登录、库存、付款选项和最终下单必须分别验收。
